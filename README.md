# Data Analysis & Coding Projects

A collection of data analysis, visualization, machine learning, and Excel dashboarding projects.

## Projects

### 1. Australia Wildfire Dashboard (`Dash_wildfire/`)
- **Files:** `Dash_wildfire.py`
- **Summary:** Interactive web dashboard filtering historical Australian wildfire data by region and year to visualize monthly average estimated fire area (pie chart) and vegetation fire pixel counts (bar chart).
- **Tools & Libraries:** Python, Dash, Plotly (`express`, `graph_objects`), Pandas

### 2. Automobile Sales Recession Analysis (`DV0101EN_Automobile_Sales/`)
- **Files:** `DV0101EN-Final-Assign-Part1.ipynb`, `DV0101EN-Final-Assign-Part1-v1.jupyterlite.ipynb`
- **Summary:** Exploratory data analysis and visualization of historical automobile sales trends across multiple economic recession periods.
- **Tools & Libraries:** Python, Pandas, NumPy, Matplotlib, Seaborn, Folium, Jupyter

### 3. House Sales in King County, USA (`House_Sales_King_County/`)
- **Files:** `House_Sales_in_King_Count_USA.ipynb`
- **Summary:** Data wrangling, exploratory analysis, and regression modeling (Linear, Polynomial, and Ridge regression) to predict house prices in King County, WA.
- **Tools & Libraries:** Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn

### 4. Car Price Model Evaluation & Refinement (`Model_Evaluation_Cars/`)
- **Files:** `Model_Evaluation_and_Refinement_cars.ipynb`
- **Summary:** Model evaluation lab covering train/test splits, cross-validation, polynomial features, Ridge regression, and `GridSearchCV` hyperparameter tuning.
- **Tools & Libraries:** Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, tqdm

### 5. EV & Data Analysis Capstone Projects (`Projects - EV & Data/`)
- **Files:** `EV_cars project.xlsx`, `american_bankruptcy.xlsx`, `marketing_AB.xlsx`, `carInsurance_paul.xlsx`, `Seattle_Cost_of_Living.xlsx`, HTML dashboards, and presentation decks.
- **Summary:** Multi-topic data analysis workbooks and dashboards covering electric vehicle specs and pricing, corporate bankruptcy pivot analysis, marketing A/B testing, car insurance, and Seattle cost of living.
- **Tools & Libraries:** Microsoft Excel (PivotTables), HTML/JS Dashboards, PowerPoint

### 6. Data Visualization & Excel Labs (`certificate/`)
- **Summary:** Hands-on spreadsheet visualization labs covering car sales, Indian startup funding, fleet equipment inventory, customer demographics, and personal expenditure using charts, PivotTables, slicers, and timelines.
- **Tools & Libraries:** Microsoft Excel, Python
